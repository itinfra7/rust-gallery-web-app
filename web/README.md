`web/` contains the reverse-proxy and watchdog examples for the public-facing host.

Main contents:
- `nginx/nginx.conf`
- `alerts/alert.conf.example`
- `alerts/app-watchdog.conf.example`
- `alerts/app-watchdog.sh`
- `services/app-watchdog.rcd`

Replace the remaining `<...>` placeholders with your own domain, app address, Telegram values, and host-specific paths before using it.
